# Темп чтения

Тренажёр чтения в одном HTML-файле: без сборки, без зависимостей, тёмная тема.

## Что умеет
- **Таблицы Шульте** 3×3 – 7×7, порядок 1→N, N→1 и буквы, отметка центра, рекорды.
- **Чтение с проверкой**: вспышки слов (RSVP) с подсветкой опорной буквы или обычное чтение с замером времени.
- **Вопросы из самого текста**: после чтения программа делает пропуски в предложениях и предлагает варианты из того же текста. Работает с любым вставленным текстом.
- **Адаптивный темп**: при понимании от 80% скорость растёт на 10%, ниже 60% падает на 15%.
- **Прогресс**: график скорости и эффективной скорости (скорость × понимание), уровни, серия дней, перенос данных копированием.

Данные хранятся в `localStorage` браузера.

## Запуск
Откройте `index.html` в браузере или включите GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).

## Идеи на потом
Периферическое зрение, саккады, антисубвокализация, генерация вопросов через LLM.
